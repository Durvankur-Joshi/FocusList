# FocusList

A fast, accessible, frontend-only productivity task manager designed to help you focus on what matters.

## Features

- Create tasks
- Edit tasks
- Complete tasks
- Delete tasks
- Priority levels (High, Medium, Low)
- Search by task title
- Status filters (All, Active, Completed)
- Priority filters (All, High, Medium, Low)
- Real-time task statistics (Total, Completed, Pending)
- localStorage persistence with fault-tolerant parsing
- Responsive UI across mobile, tablet, and desktop
- Comprehensive accessibility (ARIA, keyboard navigation, visible focus indicators)

## Tech Stack

- React
- TypeScript
- Vite
- Tailwind CSS
- Lucide React
- Vitest
- React Testing Library
- ESLint

## Run Locally

Install dependencies:

```bash
npm install
```

Start development server:

```bash
npm run dev
```

## Verification

Run linter:

```bash
npm run lint
```

Run test suite:

```bash
npm run test
```

Create production build:

```bash
npm run build
```
